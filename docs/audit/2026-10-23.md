# Audit 2 of 2 (Run 10), 2026-10-22 to 2026-10-23

The maintainer counts the pre-beta bug review as Run 10's second audit (2026-10-25). That
review was not run from the Run 10 prompt: it was asked for as "a comprehensive review for bugs
before the beta", then for the fixes. This report gathers what it did, after the fact, and says
which items of the Run 10 prompt it did not cover. Details are in docs/STATUS.md and the ADRs.

## 1. What was done

- **Round 1** (PR #17, merged as 36851f9; [ADR-0027](../adr/0027-pre-beta-review-fixes.md)).
  Seven parallel reviews (num and kernel tools; the kernel core; claims; lang; scene and export;
  editor; web), each finding reproduced by a script. `pnpm verify` was green on the base
  (5c97751, 2443 tests). Eight findings that broke "nothing silently wrong" or crashed the page
  were fixed, each with a test that failed first: false undirected angle claims at the ends of
  θ's range; false `on`/`tangent` claims in small figures; nearly coincident circles meeting at
  a fake double point; drag-end rounding flipping a dependent's selector; the tangent tool's
  coincidental `other(Q)`; Asymptote near tangencies; a verdict shown on another claim after
  undo; a blank page with blocked storage.
- **Round 2** (PR #18, merged as de3aaf2; [ADR-0028](../adr/0028-pre-beta-review-round-2.md)).
  Six further reviews hunted medium bugs (about thirty new ones, one high: `a/2/3` read as
  a/(2/3)); with the ten medium bugs round 1 left open, six parallel fixers fixed them, one
  commit and one failing-first test per bug.
- **On the same PR** ([ADR-0029](../adr/0029-style-card-and-repeated-constructions.md)), two
  maintainer requests, not audit findings: the Geomdraw-style style card with per-object
  opacity, and no repeated constructions.
- CI: green on PR #17 (ci 39872534574, tex 39872534595) and on PR #18's last code commit 38d4bc8
  (ci 39978413556 and 39978406176, tex 39978413656, deploy 39978406286). Test count 2443 → 2932.
