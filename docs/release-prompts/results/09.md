PWA save safety, stable geometry/sampling and native source editor. Incorporated task 10's
completion-caret fix `2145780` and compact-help/meaningful-notice fix `d1793e3`. No old
textarea-only screenshot is treated as evidence of the composed source experience.

regressions failed before correction (390×844 and 390×380). The final layout requires at least
120 visible pixels of native source, keeps long Editor help collapsed, and uses an in-flow,
scrollable panel at very short heights. A new expanded-phone refusal test exposed overlapping
selection/notices; stacking those controls and measuring the sheet clearance fixes visibility.

by task 10, plus reachable-control fixture corrections. Iteration 2: 90/93 passed, including

canvas re-entry). A later short-source check found harmless fractional-pixel bottom rounding;
the final requirement measures at least 120 visible pixels rather than requiring the entire
flex-grown field to end at an integer viewport coordinate. No old tolerance was changed.

See ADR-0074 for each deliberate frozen interaction-fixture migration. Existing exact rename,
