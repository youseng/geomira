### Fractional canvas coordinate integration correction

Responsive CSS exposed a real mismatch between the display's logical integer size and
its fractional CSS rectangle. A failing-first native Chromium regression independently
mapped the delivered event to the drawn view: expected A=(-0.016,0), actual
A=(-0.02,-0.0022). Input/wheel/overlay/long-press projection now uses the logical/CSS ratio;
figure and preview raster scales independently account for rounded backing dimensions.
There is no extra rectangle read in ordinary drag renders without a selection box.

Firefox CI also quantizes requested mouse y=371.4000015 to delivered client y=371.
Strict fixture expectations now use an independent actual-event math oracle, preserving
byte-for-byte canonical/script equivalence, exact undo, inverse reflection and separate
exact typed-coordinate assertions. No production rounding helper, synthetic pointer
dispatch, relaxed assertion/tolerance, even-pixel layout or snapshot update is involved.
ADR-0074 lists the frozen fixture changes. Local Firefox headless launch was attempted
with its existing binary and remained unavailable (graphics/sandbox startup timeout).
Final CI must verify Firefox/WebKit on the integrated source.
