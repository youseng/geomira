## Implemented

- Shared sampling multiplies all fixed literal radii by one exact common similarity
  scale. Free points/gliders still change; fixed ratios and dependencies survive.
  Randomize retains this scale instead of independently rounding each radius.
- Randomize and retained local/global jobs validate sampled domains, including inputs
  unrelated to the claim. Zero/negative/nonrepresentable radii, reversed/equal ranges,
  out-of-range parameters, indistinguishable floating bounds and zero stereo pairs
  refuse explicitly. Invalid inputs do not change the source or editor history.
- Retained worker message handling returns structured invalid job results instead
  of a RangeError/error transport. Public testing/discovery remains disabled.
- Strict circular ordering rejects coincident two-point groups, including parsed
  aliases, and uses the existing BAND margin for near-coincidence.
- Retained-only discovery freshness and large-live-claim performance remain explicit
  unresolved [reactivation gates](../../claims-reactivation.md). They do not expose
  public controls or affect public live verdicts, which remain unmounted.

## Limits and integration

Seed determinism holds within this sampler version; corrected samples can differ
from older versions. Long fixed radius literals may retain more digits than free
coordinates so their ratios remain exact. Local browser checks were Chromium only;
Firefox/WebKit and final performance budgets belong to composed validation.

Add `randomize-integrity` to the public single-file project's fileSpecs selection
when merging the shared Playwright configuration with prompts 03/11. The normal
public/internal desktop and phone projects already select this spec.
