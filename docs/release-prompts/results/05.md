# Prompt 05: properties, undo and inherited visibility

Base: `f95e0056c9e2cb73d23c6dac900acaf9e7f1a06a` (main including PR #40).
Implementation branch: `codex/release-05`. Integration acceptance is pending root checks.
Decision: [ADR-0070](../../adr/0070-properties-follow-document.md).

## Behavior

- Valid pending names commit before canvas/Fit/close/Escape/switch dismissal. Blur, Enter
  and the Rename button recheck the live document and cannot add a duplicate rename.
- Invalid or locked pending names preserve the document and dismissal leaves a persistent
  refusal explaining why the draft was not applied. Removed objects close without recreation.
- Label, z, offset and digits fields acknowledge their current document value. Undo/redo,
  Reset and external changes replace stale text; local partial numbers and caret survive
  ordinary typing. The complete card is not remounted on each change.
- The existing scene resolver now supplies property inheritance, row hidden state and
  selection show/hide. Showing an inherited-hidden image writes only `hidden=false` and
  leaves its source hidden; normal Show still removes hidden. One batch is one undo.
- Rows distinguish hidden layers/zero opacity from an object's hidden style. Undefined
  objects retain their reason; an object eye never enables a layer. The scene retains
  its separate coincident-image suppression policy.
