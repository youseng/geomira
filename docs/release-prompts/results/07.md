## Reproduction and resulting behavior

The first new five-test run failed four tests: area was 0 instead of 0.5 at the
100000000 translation; conic incidence was ambiguous at 100000 and off-curve at
±1000000. The origin conic test already passed. Those regressions now pass.
Point/polygon areas use an origin-relative, field-generic shoelace formula.
Conics retain a local polynomial through numeric consumers and transforms; no
EPS/BAND, sampling, claim capability or input coordinates are altered.

New kernel tests compare FloatField against RationalField at offsets 0, 100000,
±1000000 and scales 0.5, 1 and 8, covering every defining point, tangent validity,
true off-curve rejection, type/center, line intersections, gliders and translated
images. A fixed-seed dyadic property checks incidence/tangent normals. Further
regressions cover translated conic/conic intersections and all four common tangent
branches. Area covers polygon/points, orientation, collinearity and ±100000000.
New scene tests retain radius 5 and correct center through parametrization.
Built-app tests display 0.50, draw the translated tangent, export conic+tangent to
SVG and retain undo/redo construction text.

## Limits and integration

Public claim testing remains disabled. Exact RationalField/ModP construction, canonical
file syntax and field-oracle numeric ordering are unchanged. The optional chart is derived
precision metadata and evaluator finite/range checks inspect it separately. Genuine
near-degeneracies, unavailable exact roots and non-representable supplied double
coordinates retain their existing honest failure behavior. A rounded ill-conditioned
projective map still has finite precision; local coordinates cannot create missing input
information. No physical device, Firefox/WebKit or assistive-technology run was performed
for this subtask; final integration CI owns supported-engine coverage.

## Integration follow-up

Combined CI found three additional failures, reproduced locally: the original large
ellipse degeneracy case, the mutation-shard partition, and two stale last-digit
coefficient entries in the editor's conic baseline. The large ellipse issue was a
real regression: a stationary chord midpoint had zero gradient, and its dimensionless
Q was incorrectly compared to the length band. A failing new regression demonstrated
it at scale 100000000 before the fix. The new fallback uses signed physical
half-chord length at zero gradient. EPS/BAND and all original assertions are unchanged.
Additional coverage rejects a nonexistent center-crossing hyperbola chord.

The kernel mutation inventory now covers all extracted/new numeric modules. Only the
two inspected baseline coefficients are updated from tiny residuals to zero; a new
RationalField oracle requires those exact zeros mathematically. ADR-0072 records the
fourth changed frozen data file. Initial reproduction: 3 failed / 391 passed across
full degeneracy, editor figure-baseline and mutation-shard suites. With fixes and new
regressions: 425 passed in 4 files (full degeneracy, all figure baselines, mutation-shard
partition and translation stability); 43 additional close conic/scene/export regressions
passed in 8 files, including the 200-figure eccentric theorem. TypeScript and targeted
ESLint passed. No full verification, push or deployment was performed by this subtask.
