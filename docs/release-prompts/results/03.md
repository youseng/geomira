# Prompt 03: portable documents and reliable sharing

Base: f95e0056c9e2cb73d23c6dac900acaf9e7f1a06a (main including PR #40).
Implementation and focused checks completed. Root owns combined verification, CI and final
acceptance; this result does not claim a publication or a completed whole-repository verify.

## Result

- File New/Open/Save/Save As uses canonical versioned `.geo`, validates entire input before
  replacement and creates distinct recovery identities for duplicates. File limits are
  2 MiB UTF-8. Invalid/truncated/future files or failed reads leave the editor usable.
- EditorStore.textDraft is shared with the panel and file operations. Current valid pending
  text is included in Save; invalid/stale drafts have explicit choices and raw `.txt` backup.
  The visible Unapplied text draft label prevents local/downloaded status covering the draft.
- Pre-confirmation Cancel preserves document/history/draft/recovery. Continue enters an
  explicit commit phase with progress text, disabled controls/Cancel and ignored Escape.
  A failure unlocks the choices and keeps the latest figure/draft/pending save available.
  This is deliberate: cancellation is never claimed after the storage transaction or an
  explicit draft application has started. No rollback overwrites intervening user edits.
- Async file reads carry generation tokens. Cancel, a newer read/action, or disposal makes
  obsolete completions inert. Confirmed replacement rejects intervening editor changes.
- Checked public share offers keep the existing 100,000-character text and 20,000-character
  checksum-inclusive payload limits. Oversize figures get a complete canonical file fallback.
  File-origin links use SITE_URL; hosted links retain deployment paths. No uploads occur.
- All file dialogs reuse Modal. Public claims remain inert and no job dispatch is restored.

## Final-audit follow-up: update safety

At assembly base 75396de the audit found that PWA Reload to update saved only the canonical
figure and discarded raw Text/Command drafts. A new controlled-worker browser regression
failed before the fix: the page navigated and the unfinished source disappeared.

SafeUpdate now refuses reload with an accessible Update paused notice, exact raw-source or
command backup, and a review action. Active IME text is shared transiently with TextApplier;
no document format, persistence schema, implicit execution or language behavior changes.
The update checks source, command and conflicts before saving and again after it completes,
plus document identity/drag state, so edits arriving during I/O cannot be lost. Existing
Apply/Revert/finish/clear actions remain the explicit way to resolve drafts before retrying.
