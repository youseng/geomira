# Workspace controls

Press Ctrl+K (⌘K on Mac) to focus **Find a tool**. Focus the empty field to see recent tools. Search by tool name, identifier or construction operation
(for example **circumcentre**, **midpoint**, **perp** or **apply map**). Arrow keys choose a
result; Enter selects it; Escape closes the list. Selection-first inputs work just as they
do in the palette. Recent tools reuse the same catalog. Public builds do not expose claim
testing or discovery through either list.

The complete grouped palette stays available. Tab enters its last focused tool once, then
leaves the palette. Up/Down move within the desktop toolbar; Left/Right follow the phone
strip; Home/End go to its ends. Native text-field arrows continue to edit text.

On desktop, **Hide panels** makes room for the canvas and **View → Show panels** restores the sidebar.
Drag its left edge or focus the **Resize panels** separator and use arrow keys, Home or End.
The width is constrained to preserve drawing space. Collapse and resize preserve text drafts
and do not add geometry undo entries.

On phones, a tab opens a panel in the scrollable page. **Expand panel** and **Compact
panel** change its editing space. The figure stays above it; scroll down to tools and the
command bar, or use **Hide panels** to return to drawing. At short heights, **View → Show all tools** reveals
the complete palette. Source and exposed drawing space each retain at least 120 pixels;
**Editor help** expands shortcut/formatting details. Native keyboard behavior depends on
the actual browser/device.

**View → Pan canvas** drags the view, including over points; switch it off to resume construction and Move.
The existing gestures remain: left-drag empty canvas in Move to box-select, right/middle-drag
to pan, touch pan/pinch, wheel zoom, Escape to cancel picks, and 0 to fit. Select one object
and choose **Properties**, or continue using right-click/long-press to edit its style/name.
The status line shows the current tool, picked names and expected next input.

The dismissible **Getting started** guide offers points, a starter triangle, search, Move, text and export.
It never replaces existing geometry or unapplied text. Starting an action clears the guide
from the canvas. The document title opens File. The save status opens Recovery. **View** includes
Pan canvas, Show panels and Getting started. **More actions** (⋯) contains examples,
help and settings. Export opens directly from the toolbar.

Panel layout, recent tools and guide dismissal are best-effort preferences in this browser.
They are separate from saved constructions, downloads and geometry history. If preference
storage is unavailable, the controls still work during the session. Use File actions and
the persistent local save/recovery state for document protection.

Tool, selection and Zoom controls occupy a reserved row above the drawing: selecting a
point cannot put a button over it. Long warnings and update/recovery actions appear in a
separate page section with their full messages. Header menus open below their trigger or the compact header; use the same menu button to close them. Explicit tool choices and
successful command-bar actions dismiss the first-use guide.
